# FamilyHelper

Android-приложение для совместного планирования семейных дел: общий список задач, приглашения участников и обсуждение задач.

## О проекте

FamilyHelper помогает распределять домашние дела между членами семьи. Пользователь создаёт семью и приглашает родственников. После этого все участники видят общий список задач, отмечают выполненные и обсуждают их в комментариях.

## Возможности

- **Семья**: создание семьи, приглашение участников по логину, входящие и исходящие приглашения, список участников.
- **Задачи**: название, описание, сфера (дом, работа, дети), приоритет и дата.
- **Отметка о выполнении** с указанием, кто выполнил задачу.
- **Комментарии** к задачам.
- **Профили**: свой профиль с аватаром и маской ввода телефона, просмотр профилей участников.
- Регистрация с проверкой уникальности логина, вход и восстановление пароля.

## Технологии

- Java, Android SDK (minSdk 24, targetSdk 36), Material Components
- Firebase Authentication, Cloud Firestore
- Cloudinary для хранения аватаров, OkHttp
- Glide для загрузки изображений

## Структура

```
app/src/main/java/com/example/familyhelper/
  ui/activities/   вход, регистрация, семья, приглашения, профили
  ui/adapters/     списки задач, участников, приглашений и комментариев
  data/models/     пользователь, семья, приглашение, задача, комментарий
  utils/           поле ввода телефона с маской
```

## Запуск

1. Откройте проект в Android Studio и добавьте файл `app/google-services.json` от своего проекта Firebase.
2. Создайте файл `config/AppConfig.java` (в репозиторий не добавляется) с константами `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET` и `CLOUDINARY_UPLOAD_URL`.
